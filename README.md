# java_spring_my_school

## Description
This is a Spring Boot web application designed for managing contacts and holidays. It provides a user-friendly interface to interact with the data and perform various operations.

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd java_spring_my_school
   ```
2. Ensure you have Java 22 and Maven installed on your machine.
3. Build the project:
   ```bash
   mvn clean install
   ```
4. Run the application:
   ```bash
   mvn spring-boot:run
   ```

## Usage
Once the application is running, you can access it in your web browser at `http://localhost:8080`.

## Features
- Manage contacts
- Manage holidays
- User-friendly web interface

## Dependencies
- Spring Boot 3.3.3
- Spring Boot DevTools
- Spring Boot Starter Thymeleaf
- Spring Boot Starter Web
- Lombok
- Spring Boot Starter Test
